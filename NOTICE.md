## What was changed in this fork

The Kotlin package names were intentionally left as `moe.rukamori.archivetune.*` so the
fork can keep pulling upstream updates. The changes made here are:

| Change | Upstream value | Fork value |
| --- | --- | --- |
| Application ID | `moe.rukamori.archivetune` | `io.github.aeee123.koitune` |
| Gradle root project name | `ArchiveTune` | `KoiTune` |
| App label | `ArchiveTune` | `KoiTune` |
| Debug / Nightly labels | `ArchiveTune Debug` / `ArchiveTune Nightly` | `KoiTune Debug` / `KoiTune Nightly` |
